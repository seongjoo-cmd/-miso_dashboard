    구글 드라이브 연결

    구글 드라이브에서 녹취 폴더를 열었을 때의 주소를 붙여넣으세요.

    1. 스크립트 복사를 누르세요. 대시보드 주소·연동 키·폴더가 모두 들어 있어요.
    2. 녹취 폴더가 보이는 회사 구글 계정으로 script.google.com 새 프로젝트를 열고, 있던 내용을 지운 뒤 붙여넣고 저장(💾)하세요.
    3. 위쪽 함수 목록에서 설치를 고르고 실행 → 권한 허용. 끝이에요. 이후 5분마다 새 녹취가 들어와요.

    [동기화] 버튼 켜기 (선택)

    1. 스크립트 화면 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
    2. 다음 사용자 인증 정보로 실행: 나 · 액세스 권한: 회사(Miso, Inc.)의 모든 사용자 → 배포
      [동기화]를 누르면 새 탭이 열려 회사 계정으로 동기화해요. '모든 사용자'로 배포하면 탭 없이 바로 돼요.
    3. 나온 웹 앱 URL을 아래에 붙여넣고 저장하세요. 녹취 화면에 [동기화] 버튼이 생겨요.

    연동 키는 비밀번호처럼 다뤄 주세요. 녹취 파일은 드라이브에 그대로 있고, 대시보드에는 목록 정보만 들어와요.
